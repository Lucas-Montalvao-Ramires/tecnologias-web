# 📘 Cadastro de Itens

Aplicação web desenvolvida como parte da disciplina de **Tecnologia Web**, com o objetivo de praticar HTML, CSS e JavaScript.

---

## 🚀 Como executar o projeto

Você pode executar este projeto de duas formas:

### ✅ Opção 1: Abrindo diretamente o arquivo HTML

1. Acesse a pasta do projeto no seu computador.
2. Localize o arquivo `index.html`.
3. Clique duas vezes sobre ele para abrir no navegador.

> 💡 Essa opção funciona direto, sem necessidade de instalação de nada.

---

### ✅ Opção 2: Usando o Live Server (recomendado)

> Essa opção simula um ambiente de desenvolvimento real com servidor local.

1. Abra o projeto no Visual Studio Code.
2. Vá até o menu lateral de extensões (ou pressione `Ctrl + Shift + X`).
3. Procure por **Live Server** e clique em **Install**.
4. Com o projeto aberto, clique com o botão direito no arquivo `index.html`.
5. Escolha a opção **Open with Live Server**.
6. O navegador abrirá automaticamente em um endereço como `http://127.0.0.1:5500`.

---

## 🛠️ Funcionalidades

- ✅ Cadastro de itens com nome e descrição
- ✅ Validação dos campos obrigatórios
- ✅ Listagem dinâmica com atualização automática
- ✅ Remoção de itens da lista
- ✅ Navegação entre tela de cadastro e listagem
- ✅ Interface responsiva para celular e desktop
